# Python CLI To-Do List App

A Command-Line Interface (CLI) application for managing daily tasks, built with Python using Object-Oriented Programming (OOP) and JSON file persistence[cite: 1].

## Features
- **Task Management:** Add, view, complete, and delete tasks[cite: 1].
- **Data Persistence:** Tasks are stored in `tasks.json` and persist across sessions[cite: 1].
- **Automatic Re-indexing:** Deleting a task cleanly updates the remaining task IDs[cite: 1].

## Concepts Used
- Object-Oriented Programming (Classes & Methods)[cite: 1]
- JSON File I/O (`json.dump` & `json.load`)[cite: 1]
- Exception & Input Validation[cite: 1]
